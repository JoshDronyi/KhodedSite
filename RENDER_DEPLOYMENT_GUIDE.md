## 📦 Pre-Deployment Preparation

### 1. Dockerfile Optimization for Render

Your current Dockerfile is Render-compatible, but let's add production optimizations:

**Current Dockerfile Analysis**:
- ✅ Multi-stage build (reduces image size)
- ✅ OpenJDK 19 (compatible)
- ✅ Exposes port 8080 (Render standard)
- ✅ Uses Kobweb export for static generation

**Recommended Additions** (create `Dockerfile.render`):

```dockerfile
#-----------------------------------------------------------------------------
# Render.com optimized Dockerfile for Khoded application
# Based on existing Dockerfile with production optimizations
#-----------------------------------------------------------------------------

ARG KOBWEB_APP_ROOT="site"

#-----------------------------------------------------------------------------
# Build Stage
FROM openjdk:19-jdk-slim AS export

ENV KOBWEB_CLI_VERSION=0.9.15
ARG KOBWEB_APP_ROOT

# Copy the project code
COPY . /project

# Update and install required packages
RUN apt-get update \
    && apt-get install -y curl gnupg unzip wget \
    && curl -SLO https://deb.nodesource.com/nsolid_setup_deb.sh | bash -  \
    && chmod 500 nsolid_setup_deb.sh \
    && ./nsolid_setup_deb.sh 21 \
    && apt-get install nodejs -y \
    && npm install -g npm@10.5.0 \
    && npm init -y \
    && npx playwright install --with-deps chromium \
    && apt-get clean \
    && rm -rf /var/lib/apt/lists/*

# Fetch Kobweb CLI
RUN wget https://github.com/varabyte/kobweb-cli/releases/download/v${KOBWEB_CLI_VERSION}/kobweb-${KOBWEB_CLI_VERSION}.zip \
    && unzip kobweb-${KOBWEB_CLI_VERSION}.zip \
    && rm kobweb-${KOBWEB_CLI_VERSION}.zip

ENV PATH="/kobweb-${KOBWEB_CLI_VERSION}/bin:${PATH}"

WORKDIR /project/${KOBWEB_APP_ROOT}

# Optimize Gradle memory for Render's containers
RUN mkdir -p ~/.gradle && \
    echo "org.gradle.jvmargs=-Xmx512m" >> ~/.gradle/gradle.properties && \
    echo "org.gradle.parallel=false" >> ~/.gradle/gradle.properties && \
    echo "org.gradle.daemon=false" >> ~/.gradle/gradle.properties

# Build the application
RUN kobweb export --notty

#-----------------------------------------------------------------------------
# Production Stage
FROM openjdk:19-jdk-slim AS run

ARG KOBWEB_APP_ROOT

# Install PostgreSQL client for database operations
RUN apt-get update \
    && apt-get install -y postgresql-client curl \
    && apt-get clean \
    && rm -rf /var/lib/apt/lists/*

# Copy built application
COPY --from=export /project/${KOBWEB_APP_ROOT}/.kobweb .kobweb

# Copy database migrations
COPY --from=export /project/${KOBWEB_APP_ROOT}/src/jvmMain/resources/KhodedSiteData/ ./migrations/

# Health check for Render
HEALTHCHECK --interval=30s --timeout=10s --start-period=60s --retries=3 \
    CMD curl -f http://localhost:8080/health || exit 1

# Use PORT environment variable (Render requirement)
ENV PORT=8080
EXPOSE $PORT

# Production startup script
RUN echo '#!/bin/bash\n\
echo "Starting Khoded application..."\n\
echo "Database URL: $DATABASE_URL"\n\
echo "Port: $PORT"\n\
# Run database migrations if DATABASE_URL is set\n\
if [ -n "$DATABASE_URL" ]; then\n\
    echo "Running database migrations..."\n\
    # Add migration logic here if needed\n\
fi\n\
echo "Starting server..."\n\
.kobweb/server/start.sh\n\
' > /start.sh && chmod +x /start.sh

ENTRYPOINT ["/start.sh"]
```

### 2. GitHub Actions Integration

**Create `.github/workflows/render-deploy.yml`:**

```yaml
name: Deploy to Render

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v4
    
    - name: Set up JDK 19
      uses: actions/setup-java@v4
      with:
        java-version: '19'
        distribution: 'openjdk'
        
    - name: Setup Gradle
      uses: gradle/gradle-build-action@v2
      
    - name: Run tests
      run: ./gradlew test
      working-directory: ./site

  deploy:
    needs: test
    runs-on: ubuntu-latest
    if: github.ref == 'refs/heads/main'
    
    steps:
    - name: Deploy to Render
      uses: johnbeynon/render-deploy-action@v0.0.8
      with:
        service-id: ${{ secrets.RENDER_SERVICE_ID }}
        api-key: ${{ secrets.RENDER_API_KEY }}
```

**Required GitHub Secrets:**
```bash
# Add these in GitHub repository settings
```
